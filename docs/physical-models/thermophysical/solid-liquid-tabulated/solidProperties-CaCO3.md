# `CaCO3`

## 一句话

预置固体物性库条目 `CaCO3`。

## 适用条件（求解器 / 场 / 前提）

- 适用: 需要 `solidProperties` RTS 的颗粒/灰分等模型

## 字典示例

```c++
type CaCO3;
```

## 参数表

预置常数物性。

## 控制方程与关联式

Calcium carbonate (limestone)
